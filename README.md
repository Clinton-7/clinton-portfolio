# Clinton Nnoshiri — Portfolio

Personal portfolio website of Clinton Nnoshiri, WordPress & Elementor developer.

Plain HTML, CSS and JavaScript — no build step. Deployed on Vercel; every push to `main` goes live automatically.

## Editing
- **WhatsApp number, email, projects, reviews:** edit the top of `main.js` (`CONFIG`, `PROJECTS`, `REVIEWS`).
- **Text on the page:** `index.html`
- **Colours & styles:** `styles.css` (colour variables at the top)
- **Images:** `assets/`

Project screenshots are captured live from each site via WordPress mShots.
